# AXIOM

A minimalist, Apple-inspired calculator web app — clean UI, smooth micro-interactions, dark mode, and full keyboard support. Built with vanilla HTML, CSS, and JavaScript.

![AXIOM Calculator](EmpireX.jpg)

## Features

- 🎨 **Minimalist Apple-inspired design** — soft shadows, glossy button highlights, and a clean neutral palette
- 🌗 **Dark mode** — toggle with one click, preference saved automatically
- ⌨️ **Keyboard support** — full calculator control without touching the mouse
- 📱 **Fully responsive** — fluid sizing that adapts smoothly from desktop to small mobile screens
- 🧮 **Calculation history** — see your last operation faintly above the display
- ✨ **Micro-interactions** — spring-style button press animation and smooth transitions

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0-9` | Enter digits |
| `.` | Decimal point |
| `+` `-` `*` `/` | Operators |
| `Enter` or `=` | Calculate result |
| `Backspace` | Delete last character |
| `Escape` | Clear all |

## Tech Stack

- HTML5
- CSS3 (custom properties, `clamp()` for fluid sizing, CSS Grid)
- Vanilla JavaScript (no frameworks or dependencies)

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/ARiA-Zanganeh/axiom-calculator.git
   ```
2. Open `index.html` in your browser — no build step or dependencies required.
